First time on this computer? One-time printer setup about 2 min

Windows keeps printer settings separately for each person, so everyone does this once on their own login. After that, you can ignore this section.

  1. Open the printer settings

    Click the Windows search bar, type printers and scanners, and open Settings. Select ZDesigner ZD411-300dpi ZPL from the list, click Printer properties, then click Preferences…

  2. Set the label size

    On the Page Setup tab, change these three settings, then click Apply:

    Width1"
    Height0.5"
    Rotation180° - Portrait

  3. Print one label to test

    Use the blue button above and check the label. If the text looks off-center, go to the next step. If it looks fine, you're done.

  4. Only if it's off-center: adjust the left offset

    Go back into Preferences, open the Print Options tab, click the up arrow beside Left under Offsets until it reads 0.1", then click Apply and print another test label.

Printing tips
  1. In the print window, choose the ZD411 printer.
  2. Paper size should read 1 x 0.5 in, margins None, scale 100%.
  3. Turn off "Headers and footers" if it is shown.
  4. Wrong output? Tell your supervisor, do not hand-correct the label.
